Keep this on localhost

Graft runs Claude with write access to whatever repo you point it at, and has no login of its own. Claude drafts a plan for your approval before writing code, and never runs git commit or git push — you review the diff and commit yourself. Each run is confined to its own worktree, so it can't touch your main checkout or another ticket's work.
